# 本体（Wiki 组织骨架）——示例模板

> 用法：`cp Meta/ontology.example.md Meta/ontology.md`，把示例换成你自己的。
> `interest-profile.md` 管「什么值得读」；本文件管「读进去之后怎么沉淀」。
> 机器唯一依赖：下面「领域」表里的受控 domain 标签（提炼/编译/审批都读它）。
> 分类只有两套：`domain` 受控单继承（只能取下表的值），`tags` 自由多值（不受本文件
> 约束）。想按概念聚类就加 tag，别在本文件里再添第二套分类清单。
> 下面是一份**虚构示例**，只演示写法；领域名、标签、说明都按你自己的情况改。

## 领域（受控清单，改标签 = 改分类法）

| 领域 | 标签 | 说明 |
|---|---|---|
| 工作 | `#work` | 示例：主业判断与经验沉淀 |
| 技术 | `#tech` | 示例：工具、方法与实现细节 |
| 阅读 | `#read` | 示例：书籍、长文与作者观点 |
| 家庭 | `#home` | 示例：家人与孩子的观察 |
| 生活 / 杂项 | `#life` | 示例：健康、运动、日常杂项 |

## 边界

只放分类骨架；不写判据（归画像）、不写事实（归 wiki 页）、不写概念清单（归 tags）、
不追求完备。

★ 本文件除「领域」表之外的文字，程序一条都不读。
